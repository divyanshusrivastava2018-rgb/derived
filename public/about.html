What powers this site

The catalog you see on Courses is loaded from a small Express API with JSON persistence and optional file uploads. That means you can prototype quickly, then swap storage for a database without rewriting the whole UI.

Live Classes and the Research Blog are first-class pages in the same design system — so navigation feels continuous whether you are watching, reading, or checking Pricing.
